KhataAI — WhatsApp Payment Extraction Pipeline ↗

LLM · Agents

An agentic LLM pipeline built on LangGraph and MCP that turns unstructured WhatsApp payment messages into a 10-field Google Sheets ledger. It runs every 30 minutes, sends a daily summary, and guarantees exactly-once processing through SQLite deduplication, commit-after-write and locking, so no payment is ever logged twice.

Graph-Based Delhivery ETA Optimization ↗

Supply-Chain · Graph ML

Modeled the public Delhivery dataset of 144,867 shipment records as a directed graph of 1,657 facilities and 2,783 corridors. I added node2vec and centrality features to a LightGBM ETA model and ranked every hub by SLA-breach and betweenness risk. Fixing just the top 3 bottlenecks projects 4% less late-delivery time.

MAE 107 → 32 min −24% error vs non-graph baseline 5% → 46% legs within 15% 10× better than OSRM

Decoding Customer Value — SQL Retention Strategy ↗

Business · BI

Segmented 3,900 D2C customers into 5 loyalty tiers using MySQL CTEs, window functions and pandas features.
