CASE FILE P-06 ── AGENTS · EVALS

REFUND
GUARD

CUSTOMER SUPPORT RESOLUTION AGENT + LLM EVALUATION PLATFORM

An AI agent that takes a complaint from “where is my refund?” to a verified outcome, plus an evaluation platform that measures whether it can be trusted with money.

Built for a fictional electronics store: order status, refund request and damaged item.

THE ONE RULE
The model proposes; the application decides and executes through typed tools. No refund is ever issued without a human approval bound to one exact, immutable proposal.

VERDICT
Safety held: no duplicate refund in 248 runs, and the one forbidden action was caught by the policy evaluator.
No claim that specialists beat the single agent: they led on the main run (84% vs 76%) but trailed on repeated validation (57% vs 63%).
